# Michael James Heseltine — Academic Website

Static HTML/CSS site designed for GitHub Pages, using the content currently visible on the existing Google Site and a minimal academic layout inspired by the reference site.

## Deploy to GitHub Pages

1. Create a GitHub repository named `YOURUSERNAME.github.io`.
2. Upload the files in this folder to the repository.
3. In GitHub: Settings -> Pages -> Deploy from a branch -> `main` -> `/ (root)`.
4. Your site will be available at `https://YOURUSERNAME.github.io/`.

## Customize

- Replace the placeholder social links in `index.html`.
- Add your CV PDF as `Michael-Heseltine-CV.pdf`.
- Add publications and paper links to `research.html`.
- Add teaching details to `teaching.html`.
