# Michael Heseltine Academic Website

A lightweight static academic website designed for GitHub Pages.

## Files

- `index.html` - homepage
- `research.html` - publications, working papers, and projects
- `cv.html` - CV page with PDF download
- `style.css` - site styling
- `images/headshot.jpg` - profile photo
- `Heseltine Academic_CV Aug2026.pdf` - current CV

## GitHub Pages

1. Create a repository named `mjheseltine.github.io` on GitHub.
2. Upload the contents of this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Your site should be published at `https://mjheseltine.github.io/` after GitHub finishes deploying.

## Customization

The academic links and email address are already configured. Publication and CV content was based on the material supplied in the August 2026 CV. Replace or extend the entries in `research.html` as new papers appear.
